# 筋トレ記録 PWA

HTML/CSS/JavaScript のみ（ビルド不要）の筋トレ記録アプリ。データは端末の IndexedDB に保存されます。

- 種目を部位（胸・肩・腕・背中・足）ごとに管理。追加・名前変更・部位変更・削除ができる
  （記録のある種目を削除しても、過去の記録とグラフは残る）
- A日/B日メニューは「種目」タブで自由に編集（初期値：A日＝スクワット／ベンチプレス／ラットプルダウン・懸垂／カール、
  B日＝レッグプレス／ショルダープレス／シーテッドロウ／プッシュダウン）
- 記録画面の「＋ 種目を追加」で、部位→種目の順に選んでその日の種目を追加。テンプレートを使わない「フリー」の日も記録できる
- 各種目 4 セットの重量・回数を記録。前回の記録を入力画面に表示
- 4 セットすべて 10 回達成で「次回+2.5kg」を表示（次回は推奨重量を入力欄に表示）
- 最後の A日/B日 の記録の反対を自動で選択（フリーの日は判定に使わない。手動切替も可）
- 種目ごとの最大重量／総挙上量の推移グラフ
- 記録をテキストでコピー／共有（最新1回・7日・30日・全期間、履歴の各記録からも）。LINE 等で送る用
- JSON エクスポート／インポート（機種変更対策。記録・種目・メニューを保存。インポートは ID 単位で統合。v1 形式のファイルも読み込める）
- manifest + Service Worker でホーム画面追加・オフライン動作

## 使い方

GitHub Pages 等の HTTPS で `workout/` を公開し、スマホで開いて「ホーム画面に追加」。
ローカル確認は `python3 -m http.server` でリポジトリ直下を配信し `http://localhost:8000/workout/` を開く。

## 更新時の注意

ファイルを変更したら `sw.js` の `CACHE_NAME`（`workout-log-v3`）の番号を上げてください。
上げないと、インストール済みの端末に古いキャッシュが残ります。
