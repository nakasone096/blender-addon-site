# 筋トレ記録 PWA

HTML/CSS/JavaScript のみ（ビルド不要）の筋トレ記録アプリ。データは端末の IndexedDB に保存されます。

- A日：スクワット／ベンチプレス／ラットプルダウン・懸垂／カール
- B日：レッグプレス／ショルダープレス／シーテッドロウ／プッシュダウン
- 各種目 4 セットの重量・回数を記録。前回の記録を入力画面に表示
- 4 セットすべて 10 回達成で「次回+2.5kg」を表示（次回は推奨重量を入力欄に表示）
- 最後の記録の翌メニュー（A→B→A…）を自動で選択（手動切替も可）
- 種目ごとの最大重量／総挙上量の推移グラフ
- JSON エクスポート／インポート（機種変更対策。インポートは ID 単位で統合）
- manifest + Service Worker でホーム画面追加・オフライン動作

## 使い方

GitHub Pages 等の HTTPS で `workout/` を公開し、スマホで開いて「ホーム画面に追加」。
ローカル確認は `python3 -m http.server` でリポジトリ直下を配信し `http://localhost:8000/workout/` を開く。

## 更新時の注意

ファイルを変更したら `sw.js` の `CACHE_NAME`（`workout-log-v1`）の番号を上げてください。
上げないと、インストール済みの端末に古いキャッシュが残ります。
