# 筋トレ記録 PWA

HTML/CSS/JavaScript のみ（ビルド不要）の筋トレ記録アプリ。データは端末の IndexedDB に保存されます。

- 種目を部位（胸・肩・腕・背中・足）ごとに管理。追加・名前変更・部位変更・削除ができる
  （記録のある種目を削除しても、過去の記録とグラフは残る）
- メニュー（初期値は5分割：胸の日→背中の日→足の日→肩の日→腕の日）を「種目」タブで自由に編集。
  メニューの追加・名前変更・並べ替え・削除、各メニューの種目の追加・並べ替え・削除ができる
- 記録画面の「＋ 種目を追加」で、部位→種目の順に選んでその日の種目を追加。メニューを使わない「フリー」の日も記録できる
- 各種目の重量・回数を記録。目標のセット数（2〜5）と回数（3〜12）は種目ごとに設定（初期値 4×10）。前回の記録を入力画面に表示
- BIG3 は「重いセット（3×5）→ いつものセット（2×10）」の順で練習できるよう、重いセットの種目を自動で作ってメニューの先頭に置く。
  重いセットで 2 回続けて目標に届かなければ、10% 下げた重さを提案する
- BIG3 の重いセットには、その日の重さから計算したウォーミングアップのチェックリストを表示
  （バー×10 → 約65%×5 → 約85%×3。デッドリフトは 40kg 以上から。記録には残らない）
- 目標のセット数すべてを同じ重さで目標の回数以上できたら「次回+◯kg」を表示（次回は推奨重量を入力欄に表示）。
  増やす重さは種目ごとに 1/2/2.5/5kg から選べる（初期値：胸・背中・足 5kg、肩・腕・その他 2.5kg）。
  重さを変えながらやった日は、一番多くのセットで使った重さを次回の目安にする
- 次のメニューは「一番長くやっていないもの」を自動で選択（順番どおりに続ければ並び順に回る。フリーの日は判定に使わない。手動切替も可）
- 以前の A日/B日 の記録は、そのままの名前で履歴・グラフに残る
- 種目ごとの最大重量／推定MAX／総挙上量の推移グラフ
- 自己ベスト：保存時に「最高重量・推定MAX・同じ重さでの回数」の更新をお知らせ。種目ごとの自己ベスト一覧
  （推定MAX は Epley 式：重さ ×（1 + 回数/30）。13 回以上のセットは使わない）
- BIG3（スクワット・ベンチプレス・デッドリフト）の推定MAX の合計と、目標（初期値 300kg）までの残り。使う種目と目標は変更できる
- 記録をテキストでコピー／共有（最新1回・7日・30日・全期間、履歴の各記録からも）。LINE 等で送る用
- JSON エクスポート／インポート（機種変更対策。記録・種目・メニューを保存。インポートは ID 単位で統合。旧形式のファイルも読み込める（A日/B日のメニューは取り込まない））
- manifest + Service Worker でホーム画面追加・オフライン動作

## 使い方

GitHub Pages 等の HTTPS で `workout/` を公開し、スマホで開いて「ホーム画面に追加」。
ローカル確認は `python3 -m http.server` でリポジトリ直下を配信し `http://localhost:8000/workout/` を開く。

## 更新時の注意

ファイルを変更したら `sw.js` の `CACHE_NAME`（`workout-log-v9`）の番号を上げてください。
上げないと、インストール済みの端末に古いキャッシュが残ります。
